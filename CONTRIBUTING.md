# Contributing to VectorStep-Website

**This repo is public, but not open contribution — and not open licence.**

This repository holds the VectorStep marketing site and documentation. It's
public because GitHub Pages only builds from public repos, and its content is
published at [vectorstep.io](https://vectorstep.io) anyway. Public is not the
same as licensed, though: this repo carries no open-source licence and stays
all-rights-reserved. If you're looking for the Apache-2.0 code to fork,
that's the [VectorStep](https://github.com/bantex01/VectorStep) engine repo —
this one is the site around it, not part of the product.

Pull requests are closed unmerged, regardless of content. That's a policy
about keeping the site's copy unambiguous in authorship, not a judgement on
the patch.

## What is welcome

- **The documentation is wrong, outdated, or confusing.** Open an issue with
  the page and what was wrong — this is treated as a bug.
- **A broken page, dead link, or rendering bug.** Same as above.

Please describe problems in prose rather than pasting a suggested patch.

## What happens to pull requests

They get closed with a link to this file. Nothing personal — please don't
take the trouble to open one.

## Getting in touch

If you'd rather talk to a person, I'm at **alex@vectorstep.io**.
